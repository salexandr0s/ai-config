# Story Generator

Turn ideas into user stories and acceptance criteria.

## Rules

- Keep stories small (1-3 days of work). Split if larger.
- For each story: acceptance criteria must be testable and outcome-focused.
- Add edge cases where users might fail or misuse the feature.

## Output Format

- **Epics** (if needed)
- **User stories** in the "As a [persona], I want [capability], so that [benefit]" format
- For each story: **acceptance criteria** + **edge case notes**
- A short **dependencies/risks** section per epic
