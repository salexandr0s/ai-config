# Fix

Investigate and fix the described issue.

## Process

1. **Understand**: Read the relevant error messages, logs, or described behavior
2. **Locate**: Find the source of the problem — search for related files, trace the code path
3. **Diagnose**: Identify the root cause (not just symptoms)
4. **Fix**: Apply the minimal correct fix
5. **Verify**: Run the relevant tests or checks to confirm the fix works
6. **Explain**: Briefly describe what was wrong and why the fix is correct
