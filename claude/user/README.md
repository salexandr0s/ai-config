# Private user context templates

These blank files provide headings for mission, goals, projects, and other context. The installer copies missing templates into `~/.claude/USER`; it preserves files that already exist there.

Edit your private files in `~/.claude/USER` when adding personal information. Keep the templates in this repository empty. User profiles, working notes, account details, and session records belong outside this repository.

The `Active` and `Archived` sections let you retain context locally as it changes. Remove the placeholder comments in your local copy when they are no longer useful.
